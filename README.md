# Orvie reference page

A static product reference for Orvie, the design fork of the Asclepius dashboard.

- `index.html` is self-contained; brand fonts and screenshots live in `assets/`.
- Deployed with GitHub Pages from the repository root on `main`.
- The live demo link points at the current Cloudflare quick tunnel and can change when that tunnel restarts.
- The app source and the pilot database are private.

The page was generated from the Orvie-Web-App repository at commit `c7600d0`.
